# One Stop Center · SJKC Li Tek B

**[Buka halaman pemasangan dan ikon aplikasi](https://g-31009424-sudo.github.io/OneStopCenterLTB-App/)**

Halaman ini menyediakan pintasan ke webapp DELIMa sekolah. Kod pelayan serta data murid tidak disimpan dalam repositori awam ini.

## Pasang pada peranti

- Android: Chrome/Edge → menu ⋮ → Pasang aplikasi / Tambahkan pada skrin utama.
- iPhone/iPad: Safari → Kongsi → Tambah ke Skrin Utama.
- Komputer: gunakan pilihan pemasangan dalam menu pelayar yang menyokong aplikasi web.

Nama menu bergantung pada peranti/pelayar. Jika dibuka dalam WhatsApp atau Facebook, pilih Buka dalam pelayar penuh dahulu. Butang Pasang pintasan menyediakan panduan apabila dialog pemasangan automatik tidak tersedia.

Pintasan membuka halaman ini; butang Buka aplikasi DELIMa membawa guru ke webapp sekolah yang memerlukan akaun Google yang sah. Pengisian rekod memerlukan Internet.

## Penyelenggaraan

Sumber statik berasal daripada folder docs/ dalam repositori persendirian aplikasi. GitHub Pages menerbitkan branch main, root /. Kemas kini nombor cache dalam sw.js apabila mengubah aset pintasan.
